BTicino Classe 100X Firmware Tools

Start with README.md in this folder for installation, SSH/MQTT setup and updates.
It is the same guide as the project's online README. Detailed instructions and
validation results are in docs/; these files describe this release's source snapshot.

Keep c100x and support together. Store firmware and private settings outside the
installation folder. Building an image and flashing the intercom are separate steps.

Downloads and current online documentation:
